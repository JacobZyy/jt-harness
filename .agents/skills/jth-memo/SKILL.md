# JTH Memo

## 读取

- 开始、恢复实质任务或切换目标时先看已有线索；不足时 `jth memo recall '<关键词>' --project <ID>`，再按需 `search`。同一目标复用已读结果。
- 范围沿用项目安装配置，可用 `jth flow status` 或 `jth memo codex status` 查看，不猜项目 ID。
- `search` 默认关键词与向量混合检索；精确标识符可加 `--mode keyword`。普通读取用 `jth memo read <ID> --level evidence`；条件不全、冲突或更正用 `--level full`。
- 线索不等于已读，已读不等于采用；历史资料不覆盖当前要求。检索、读取后简报真实数量，未命中或失败如实说明，例如“JTH Memo｜检索返回 3 条，已读取 2 条”。

## 记录

有值得后续复用的事实、明确决定、更正或采用反馈时，读取[声明格式](references/declarations.md)，在最终回复末尾声明；没有则不附。

用户短回复明确接受前文方案也算决定。只记录接受的范围，批准不等于实施完成；将待声明决定和来源留在当前会话或原生计划，压缩、恢复时接续，收口前核对。

只把有后续价值的建议或推断保存为候选，不当作已确认事实。子 Agent 将发现交回主 Agent，由主 Agent 核对后声明。声明由 Stop Hook 保存，输出声明不代表已入库。
